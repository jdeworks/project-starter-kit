# my-mcp-server

An MCP (Model Context Protocol) server built with the [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk).

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Other scripts

| Script | Description |
|---|---|
| `npm run format` | Format code with Prettier |
| `npm run lint` | Lint with ESLint |
| `npm run typecheck` | Type-check without emitting |

## Tools

- `echo` — returns the input text unchanged
- `word_count` — counts the number of words in the provided text
